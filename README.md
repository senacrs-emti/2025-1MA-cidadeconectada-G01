# 🗺️ Sobre o Projeto

Este projeto é um mapa interativo de mobilidade urbana de Porto Alegre, que reúne dados de diferentes fontes e os exibe de forma simples e organizada.
Ele mostra:

## 🚌 Paradas de ônibus oficiais (GTFS da Prefeitura de Porto Alegre)

## 🚲 Estruturas relacionadas a bicicletas (estações, paraciclos, etc.) via OpenStreetMap/Overpass

## 🚆 Estações e trilhos de trem

## 📍 Localização atual do usuário, com cálculo da distância até cada ponto

O mapa utiliza Leaflet + OpenStreetMap e integra APIs públicas para fornecer uma visão centralizada das opções de transporte e infraestrutura urbana da cidade.

Ideal para estudos, visualização de mobilidade, integração em projetos e experimentos com dados abertos.
